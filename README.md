# Менеджер задач (Матрица Эйзенхауэра) 📱

Кроссплатформенное мобильное приложение для Android, разработанное на C# (.NET MAUI). Приложение помогает расставлять приоритеты в задачах, автоматически распределяя их по 4 квадрантам матрицы Эйзенхауэра.

## 🛠 Технологический стек
* **Язык:** C#
* **Фреймворк:** .NET MAUI (XAML для UI)
* **База данных:** SQLite (библиотека `sqlite-net-pcl`)
* **Среда разработки:** Visual Studio 2026, Android Emulator (Pixel 7, API 31)

## ✨ Функционал
* Добавление задачи с названием и описанием.
* Отметка признаков «Срочно» и «Важно» через чекбоксы.
* Автоматическое определение квадранта (Важно и срочно, Не срочно, Срочно но не важно, Не обязательно).
* Удаление конкретной задачи или полная очистка списка.
* **Сохранение данных в локальную БД SQLite** (задачи не исчезают после перезапуска приложения).

## 🚀 Как запустить
1. Склонируйте репозиторий.
2. Откройте файл решения `.sln` (или `.slnx`) в Visual Studio.
3. Выберите эмулятор Android в верхней панели и нажмите `F5` (Запустить).

## ⚠️ Решенные проблемы в процессе разработки
* Настроен атрибут `android:exported="true"` в `AndroidManifest.xml` (требование Android 12+).
* Настроено наследование `MauiAppCompatActivity` и атрибуты `[Activity]` для корректной точки входа.
* Настроен `<TargetFrameworks>net8.0-android</TargetFrameworks>` в `.csproj` для правильной сборки APK.
